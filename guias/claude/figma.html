Figma con 20 llamadasFigma with 20 calls

El plan gratuito da veinte llamadas por mes. Se me fueron en un día, y esto aprendí para la próxima.The free plan gives you twenty calls a month. Mine were gone in a day, and here's what I learned for next time.

Conecté Figma a Claude para pasar el sistema visual de mi sitio a un archivo de diseño y, de paso, armar un carrusel para Instagram. Funciona. El plan Starter, el gratuito, permite 20 llamadas por mes, y cuentan igual las que leen que las que escriben. Se me fueron todas en un día, con el carrusel.

No lo vi venir: mirar el archivo es una llamada, dibujar es otra y sacar una captura para ver cómo quedó es otra más. Veinte llamadas son pocas si las usás para chequear y alcanzan bastante si las usás para construir. (Los planes pagos dan 200 por día, por si te sobra la plata.)

Qué cambié

Tres reglas, anotadas en la carpeta del proyecto:

  • Pocos scripts, grandes. En lugar de una llamada por botón, una llamada que arma un componente entero con sus variantes. Cuesta más pensarla, pero se paga una sola vez.
  • Nada de llamadas de verificación. “A ver si quedó bien” es una llamada gastada. Si el script está bien escrito, quedó bien; y si no, lo vas a ver igual cuando abras el archivo.
  • La captura va adentro. Pedirle una captura de pantalla es otra llamada, salvo que la función screenshot() se ejecute dentro del mismo script que dibuja. Así la vista previa viaja con el trabajo y no cuesta una más.

Con esas reglas, el plan para pasar todo el sistema visual quedó en tres llamadas y dos de reserva. Sobre el papel. Todavía no lo pude probar, porque el cupo no se renovó.

Lo que quedó a medias

El sistema visual no entró en esa tanda y espera a que se renueve el cupo. Lo anoto sin vergüenza: es lo que pasa cuando un recurso tiene tope y uno no lo había mirado. Lo mismo me pasó con la cuota de Claude, que cuento en la semana que me quedé sin cuota.

Una alternativa sin IA

Antes de gastar llamadas, preguntate si lo que necesitás es Figma. Para piezas simples, como una imagen para redes o el mismo carrusel, terminé armando un editor local que corre en el navegador y exporta PNG. No tiene tope y, una vez escrito, no gasta nada de Claude. Figma queda para lo que de verdad pide un archivo de diseño compartido.

Es la misma lógica de los hábitos: lo que se repite y tiene reglas va en un script, y la IA se reserva para lo que pide criterio.

El prompt

Vamos a trabajar en Figma con un cupo de 20 llamadas por mes. Antes de usar ninguna, armá un plan numerado de cuántas necesitaríamos, agrupando todo lo que se pueda en scripts grandes. No hagas llamadas solo para verificar. Si hace falta una captura, pedila dentro del mismo script que dibuja. Decime también qué piezas se podrían resolver sin Figma, con un editor local que exporte a PNG. Mostrame el plan y no uses ninguna llamada hasta que lo apruebe.

I connected Figma to Claude to move my site's visual system into a design file and, while I was at it, put together an Instagram carousel. It works. The Starter plan, the free one, allows 20 calls a month, and the ones that read count the same as the ones that write. All of mine were gone in a day, on the carousel.

I didn't see it coming: looking at the file is one call, drawing is another and taking a screenshot to see how it came out is yet another. Twenty calls are few if you spend them on checking and plenty if you spend them on building. (The paid plans give you 200 a day, in case you've got money to burn.)

What I changed

Three rules, written down in the project folder:

  • Few scripts, big ones. Instead of one call per button, one call that builds a whole component with its variants. It costs more to think through, but you pay it once.
  • No verification calls. “Let's see if it came out right” is a wasted call. If the script is well written, it came out right; and if not, you'll see it anyway when you open the file.
  • The screenshot goes inside. Asking for a screenshot is another call, unless the screenshot() function runs inside the same script that draws. That way the preview travels with the work and doesn't cost an extra one.

With those rules, the plan to move the whole visual system came down to three calls and two spare. On paper. I haven't been able to try it yet, because the quota hasn't renewed.

What was left half done

The visual system didn't make it into that batch and is waiting for the quota to renew. I note it without shame: it's what happens when a resource has a cap and you hadn't looked at it. The same thing happened to me with Claude's quota, which I tell in the week I ran out of quota.

An alternative without AI

Before spending calls, ask yourself whether what you need is Figma. For simple pieces, like an image for social media or that same carousel, I ended up building a local editor that runs in the browser and exports PNG. It has no cap and, once written, costs nothing in Claude. Figma stays for what really calls for a shared design file.

It's the same logic as the habits: what repeats and has rules goes in a script, and AI is kept for what calls for judgment.

The prompt

We're going to work in Figma with a quota of 20 calls a month. Before using any, put together a numbered plan of how many we'd need, grouping everything you can into big scripts. Don't make calls just to verify. If a screenshot is needed, ask for it inside the same script that draws. Also tell me which pieces could be solved without Figma, with a local editor that exports to PNG. Show me the plan and don't use any call until I approve it.
