These are templates to attach to each card's prompt. Where there are [brackets], put your own stuff.

If you want a single file with everything, here's guide-to-share.md: the guide without my data, with the templates and an interview so Claude adapts it to you. It goes with The interview that sets everything up.

  • CLAUDE-general.md, the general context with the saving rules. It goes with The file that says who you are.
  • token-economy.md, the full saving guide, to be read only when planning. It goes with How the quota gets spent.
  • CLAUDE-project.md, the template for each project, with its Status. It goes with One file per project.
  • CHANGELOG.md, the version log.
  • weekly-newsletter.md, the scheduled task's instructions. It goes with The continuous improvement newsletter.
  • CRITERIA.md and NONCONFORMITIES.md, the minimal quality system. They go with Quality without bureaucracy.
  • gasto-tokens.csv, the empty spreadsheet for logging each week's spend. It goes with Measuring spend.

If you use Claude Code, the general file goes in ~/.claude/CLAUDE.md and each project's goes as CLAUDE.md inside its folder. On claude.ai, the general one gets pasted into the personal instructions and each project's into the instructions of its Project. If you use claude.ai, wherever the prompts say “file”, read “personal instructions” or “Project instructions”.

The full guide has all the cards; the first version, on a single page, is still available in Markdown.

None of this came out right the first time. I built it a week at a time, which is exactly what the newsletter is there to remind me of.
